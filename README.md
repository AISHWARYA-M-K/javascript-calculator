# JavaScript Calculator

## About

A simple calculator built using HTML5, CSS3 and JavaScript that performs basic arithmetic operations.

## Live Demo

[View Calculator](https://aishwarya-m-k.github.io/javascript-calculator/)

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Practiced

- DOM manipulation
- Event handling
- Functions
- Object destructuring
- Input handling
- parseFloat()
- Basic arithmetic operations

## What I Learned

This project helped me understand how to collect user input from HTML elements, handle button click events, convert input values into numbers, perform calculations and display the results dynamically.
